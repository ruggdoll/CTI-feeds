# Définitions et objectifs du concept de « mode opératoire informationnel » (MOI)

- **Type** : méthodologie · **Date** : 22/01/2026 · **Groupe** : C
- **Page** : <https://www.sgdsn.gouv.fr/viginum/publications/definitions-et-objectifs-du-concept-de-mode-operatoire-informationnel-moi>

Note méthodologique définissant le **MOI** comme « un ensemble de comportements,
d'outils, de tactiques, techniques et procédures et de ressources adverses mis
en œuvre par un acteur ou un groupe d'acteurs malveillants dans le cadre
d'opérations informationnelles ». Cadre conceptuel utilisé dans tous les rapports
techniques VIGINUM. **Fiche seule** — utile comme référence pour le choix de
modélisation OpenCTI (MOI ≈ Intrusion-Set).
